# 01 - refused, then run

A complete worked run in five files: the refusal gate firing on a thin pitch, the
studio supplying what was missing, and the full wash that followed. The most
important of the two examples to read.

`1-artifact.md` is the pitch as supplied, `2-refusal-or-gate.md` is what the gate
did before running, `3-reactions.md` holds the seat-by-seat verdicts in the
ten-line contract, `4-synthesis-and-score.md` has the decision table, the
dissent, the arithmetic, the integrity check, and the call (scored 57.0, resolved
REVISE), and `NOTES.md` says what to notice.

Everything in it is invented for the example. Read it after your own first wash,
as a comparison, never instead of one.
