# 02 - strong pitch, wrong room

A complete worked run on a genuinely good pitch that the panel still says STOP
to, because the enthusiasm is concentrated in the two seats that cannot
authorize anything.

Same five files as the other example: `1-artifact.md` the pitch,
`2-refusal-or-gate.md` the gate, `3-reactions.md` the seat-by-seat verdicts,
`4-synthesis-and-score.md` the table, dissent, arithmetic, integrity check and
call (scored 55.35, resolved STOP), and `NOTES.md` what to notice.

Read it against example 01, which scored two points higher and resolved REVISE:
the lesson is to read the decision table by authority, not by count. Everything
in it is invented for the example.
