# dossiers

One file per seat: the written background a seat reads itself into before
judging a pitch, and the reason it reacts as a person rather than as a critic.
Thirteen shipped seats, numbered `01-` to `13-`, plus `DOSSIER-TEMPLATE.md` for
writing a new one.

The shipped thirteen are composites of common client-side committee patterns -
none is a real named person and none is based on any particular client. Two are
built to say no: `13-builds-it-in-house` and `12-budget-was-never-real`.

A dossier is edited, not replaced: keep the headings, change the content, and say
in `## Evidence basis` what the new content is based on. Which seats are active
is set in `../panel.json`, not here.
